# Calculadora — testes unitários

Projeto de calculadora com implementações e testes unitários em Go e Python.

## Go

```bash
go test -v
```

## Python

```bash
cd python
python -m pip install -r requirements.txt
python -m pytest -v
```

As duas versões implementam adição, subtração, multiplicação, divisão,
fatorial e potência, incluindo o tratamento dos casos inválidos definidos no
escopo.
